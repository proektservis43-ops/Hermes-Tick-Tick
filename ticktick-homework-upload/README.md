# Интеграция голосового агента (Hermes) с TickTick

Домашнее задание: настройка AI-агента, который принимает задачи голосом/текстом и заносит их в TickTick, а также напоминает о дедлайнах.

## Что делает система

```
Голосовое сообщение (Telegram)
      │  (локальное распознавание речи, faster-whisper, модель small, язык ru)
      ▼
AI-агент (Hermes Agent, LLM DeepSeek V4 Flash)
      │  (понимает смысл: «сделка по квартире во вторник» → структурированная задача)
      ▼
Скрипт tick.py (TickTick Open API v1)
      │
      ▼
TickTick (задача в списке с датой, временем, напоминанием)
      ▲
      │  (утренняя сводка в 08:00 + проверка дедлайнов каждые 30 мин — cron)
Напоминания в Telegram
```

## Возможности
- **Приём задач голосом** — русская речь распознаётся локально (приватно), агент разбирает смысл, уточняет у пользователя и заносит в TickTick
- **Приём задач текстом** — «купи молоко завтра в 18:00»
- **Списки** — задача кладётся в нужный список TickTick (Личный, Дом, Работа и т.д.)
- **Даты и напоминания** — относительные даты («в следующий вторник») переводятся в абсолютные, TickTick сам шлёт уведомление
- **Утренняя сводка** — каждый день в 08:00 приходит список: просроченное / сегодня / завтра
- **Напоминания о дедлайнах** — проверка каждые 30 минут, задачи с дедлайном в ближайшие 1,5 часа приходят в Telegram (без дублей)

## Требования
- macOS/Linux, Python 3.10+
- TickTick аккаунт с Personal Access Token (Настройки → Интеграции → API)
- AI-агент Hermes Agent (https://github.com/NousResearch/hermes-agent)

## Как воспроизвести
1. Получить токен TickTick (Settings → Integrations → API)
2. Положить его в переменную окружения:
   ```bash
   echo "TICKTICK_API_TOKEN=ваш_токен" >> ~/.hermes/.env
   ```
3. Создать задачу:
   ```bash
   python3 scripts/tick.py add --title "Купить молоко" --list "Дом" \
     --due "2026-09-20T18:00:00+03:00" --remind 30
   ```
4. Показать сводку на сегодня:
   ```bash
   python3 scripts/tick.py digest
   ```

## Особенности TickTick Open API (найдено в ходе работы)
- Чтение задач — не GET, а POST `/open/v1/task/undone` (тело: projectIds, startDate, endDate)
- Окно запроса `/task/undone` ограничено ~14 днями — скрипт бьёт запрос на чанки
- Завершение/удаление: POST/DELETE `/open/v1/project/{projectId}/task/{taskId}[/complete]`
- Для «Входящих» используется спец-ключ `inbox`
- Напоминание задачи: `"reminders": ["TRIGGER:PT30M"]` (за N минут до дедлайна)

## Безопасность
- Настоящие токены в репозиторий НЕ включены (см. `.env.example`)
- Файл `.env` имеет права 600 (только владелец)
