# Примеры работы системы

> Данные в примерах учебные/обезличенные. Настоящие токены не показаны.

## 1. Распознавание голоса (локально, русский язык)

**Модель base (до апгрейда):**
```
«Проверка сообщения, поменялся лизык»   ← ошибка распознавания («лизык» вместо «язык»)
```

**Модель small (после апгрейда):**
```
«Давай проверим голосовой ввод. Насколько второй вариант лучше первого и насколько он
правильный, понимает стилистику и изложение, особенно уже более лингвистически
развёрнутого и интересного текста»      ← без ошибок, сложная лексика распознана
```

Вывод: выбор модели распознавания речи критичен для качества (base → small убрал
ошибки на сложной русской лексике).

## 2. Голосовая диктовка → разбор смысла

**Пользователь диктует:**
> «На следующей неделе во вторник сделка по квартире. Также на следующей неделе встреча с Русланом Мамедовым»

**Агент уточняет и создаёт в TickTick:**
```
1) Сделка по квартире          — вт 15.09, 12:00, список «Личный», напоминание за 60 мин
2) Встреча с Русланом Мамедовым — вт 15.09, 18:00, список «Личный», напоминание за 60 мин
```

## 3. Примеры команд скрипта

```bash
# Создать задачу
python3 scripts/tick.py add --title "Купить молоко" --list "Дом" \
  --due "2026-09-20T18:00:00+03:00" --remind 30

# Сводка (просроченное / сегодня / завтра)
python3 scripts/tick.py digest

# Список задач на дату
python3 scripts/tick.py tasks --from "2026-09-15T00:00:00+03:00" --to "2026-09-16T00:00:00+03:00"

# Завершить / удалить
python3 scripts/tick.py complete <taskId>
python3 scripts/tick.py delete <taskId>
```

## 4. Утренняя сводка (пример вывода)

```
📋 Сводка на 15.09

🗓 Сегодня:
• Сделка по квартире [Личный] — 15.09 12:00
• Встреча с Русланом Мамедовым [Личный] — 15.09 18:00
```

## 5. Cron-задачи агента
| Задача | Расписание | Что делает |
|---|---|---|
| Утренняя сводка | ежедневно 08:00 | присылает digest в Telegram |
| Проверка дедлайнов | каждые 30 минут | напоминает о задачах с дедлайном в ближайшие 90 минут (без дублей) |
